# 修仙世界 · 三界录

单文件 HTML 修仙文字 RPG。双击即玩，无需安装、无后端、无依赖。

## 在线试玩

开启 GitHub Pages 后访问：

https://yongzhihuang1116.github.io/san_jie_lu/

## 本地运行

下载 `index.html`，用任意现代浏览器打开即可开始游戏。

## 玩法特色

- **角色创建**：详细创建（自选出身 / 灵根 / 职业）与快速随机开局（自襁褓始）。
- **境界体系**：九大境界 × 四小境；突破有失败风险，且消耗闭关岁月，寿元耗尽则坐化。
- **功法系统**：攻 / 防 / 灵 / 血四类功法，可参悟升级（Lv1→Lv3）、易修换功；战斗绝技依主修功法施展。
- **回合制战斗**：蓄力一击、运物助战（丹药 / 符箓）、敌人 AI（攻 / 防 / 蓄力）、职业克制、暴击与身法破绽。
- **三界舆图**：长安 / 洛阳 / 扬州 / 姑苏 / 锦官 / 昆仑 / 蓬莱 / 十万大山 / 云梦泽 / 妖界 / 魔界。
- **机缘系统**：探索采药随机触发奇遇；气运 ≥ 80 为「大气运」，会引动仙缘 / 洞天 / 灵脉等稀世机缘。
- **坊市六页**：买卖（价随行情浮动）/ 丹房炼丹 / 拍卖寄售 / 以物易物 / 委托收购 / 黑市赌石。
- **赛事**：比武大会、狩猎灵兽大赛。
- **姻缘与子嗣**：多候选道侣（含身世背景）、双修、受孕判定、双胎、灵根资质、赐名、择嗣继承（指定后裔全数继承灵石）。
- **灵宠系统**：狩猎降服、灵草喂养、分配装备、战斗中助战（至多 4 只）。
- **家族面板**：顶栏「🏠 家族」可览亲族、指定后裔继承灵石、赐予灵宠。
- **突发事件弹窗**：探索 / 奇遇 / 遭遇均以致命感弹窗呈现，参与感拉满。
- **大陆奇遇**：不同大陆（人 / 妖 / 魔 / 险地 / 中立）有专属奇遇事件。
- **渡劫四小阶**：渡劫期历「初 / 中 / 后 / 巅峰」，需破境丹助缘，巅峰方可飞升（永不致死）；难度整体上调。
- **比武可选手**：自选对手（境界 / 职业 / 强度具现）。
- **及冠机制**：16 岁前为「幼年」，行动受限；及冠后开启全部玩法。
- **回忆录与继承**：一世终结后载入回忆录（飞升有尊号与成就结算），可择后裔继承遗泽再启新世。

## 操作

点击按钮行动，或在输入框输入自由指令：

```
修炼 / 前往昆仑墟 / 探索 / 采药 / 出手 / 运物 / 蓄力 / 使用疗伤丹 / 休息 / 商店 / 存档
```

## 存档说明

- 存档保存在浏览器本地（`localStorage`），按设备 / 浏览器隔离，**不会上传，也不会与他人共享**。
- **换设备续玩**：在「选档」中「导出」存档码（base64），在另一台设备「导入」即可，实现随身客制化存档。
- 共三个档位，支持读取 / 导出 / 删除 / 覆盖重开。
