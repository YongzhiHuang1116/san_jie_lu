# 修仙世界 · 三界录

单文件 HTML 修仙文字 RPG。双击即玩，无需安装、无后端、无依赖。

## 在线试玩

开启 GitHub Pages 后访问：

https://yongzhihuang1116.github.io/san_jie_lu/

## 本地运行

下载 `index.html`，用任意现代浏览器打开即可开始游戏。

## 玩法特色

- **角色创建**：详细创建（自选出身 / 灵根 / 职业）与快速随机开局（自襁褓始）。
- **境界体系**：九大境界 × 四小境；突破有失败风险，且消耗闭关岁月，寿元耗尽则坐化。
- **功法系统**：剑 / 法 / 体 / 符 / 阵 / 丹 / 蛊 / 器 / 妖 / 魔十流派 + 金木水火土风雷光暗诸象功法（按灵根相合加成：同属 ×1.18、相生 ×1.08）；普通功法 Lv1→Lv3，传承功法 Lv 上限 5（世家 / 宗门 / 势力 / 机缘可获）；主修功法与职业流派相合则伤害大增、相悖则减损，战斗显伤显耗灵。
- **神识（👁）**：随境界与悟性增长、休息可恢复；助炼丹成丹率、探索外放探草、战斗识破增伤、号令更多灵宠（至高 3 只）、养宠炼器皆赖之。
- **回合制战斗**：蓄力一击、运物助战（丹药 / 符箓）、敌人 AI（攻 / 防 / 蓄力）、职业克制、暴击与身法破绽。
- **三界舆图**：长安 / 洛阳 / 扬州 / 姑苏 / 锦官 / 昆仑 / 蓬莱 / 十万大山 / 云梦泽 / 妖界 / 魔界；人界低境开局即全开，昆仑（炼虚）/ 蓬莱与十万大山（合体）/ 妖界（大乘）/ 魔界（渡劫）随修为渐进解锁，本族出身者恒开其界。
- **机缘系统**：探索采药随机触发奇遇；气运 ≥ 80 为「大气运」，会引动仙缘 / 洞天 / 灵脉等稀世机缘；大陆奇遇与机缘小概率遇<b>上古传承</b>（湮没万载的失传绝学，可修至 Lv5）。
- **坊市六页**：买卖（按城等阶限售、行情浮动、下 / 中 / 上 / 极四等灵石 + 金银多币种结算、奇货随机上架）/ 丹房炼丹（高品丹药唯丹 / 药修以对应等阶灵石秘炼）/ 拍卖寄售 / 以物易物 / 委托收购 / 黑市赌石。
- **赛事**：比武大会、狩猎灵兽大赛。
- **姻缘与子嗣**：多候选道侣（含身世背景）、双修、受孕判定、双胎、灵根资质、赐名、择嗣继承（指定后裔全数继承灵石）。
- **灵宠系统**：狩猎降服、灵草喂养、分配装备（可卸下归还行囊）、战斗中助战（至多 4 只）；16 种灵宠各具属相（金木水火土风雷光暗）与定位（攻 / 防 / 敏 / 辅），影响养成与战斗风味。
- **人际与多线伴侣**：顶栏「💞 人际」集中管理所有缘法——道侣可<b>多线并行攻略</b>，同时追求者愈众、情分衰减愈速，并行≥2 更可能惹<b>争风吃醋、约战证心</b>（伴侣与你对战，败则情缘断了，非致命）；社交结识可择「结为道侣」或「结为好友（知己）」；异族相逢亦可纳入。结为道侣者入「家族」为家人，并按缔结顺序标注<b>第N任道侣</b>（未缔结者标「缘法第N位」），子嗣亦注明与第几任道侣所出。
- **宗门系统**：出身「宗门弟子」即自动绑定一门宗门（玩家为<b>弟子</b>，非掌门，门人 2~3 名）；掌门之位后期可凭<b>比武大会夺魁</b>继任、或<b>覆灭敌宗</b>取而代之（覆灭本宗亦可另立门户）；开宗立派者即为掌门，每年消耗资源供养弟子、核心弟子外出采办献纳、招收与扩建山门；立派且有后裔时可指定其一为<b>圣子 / 圣女</b>继承宗门道统；宗门之战权衡实力，胜则夺宝扬名、或收编敌众，败则损兵折将。
- **突发事件弹窗**：探索 / 奇遇 / 遭遇均以致命感弹窗呈现，参与感拉满。
- **大陆奇遇**：不同大陆（人 / 妖 / 魔 / 险地 / 中立）有专属奇遇事件。
- **渡劫四小阶**：渡劫期历「初 / 中 / 后 / 巅峰」，需破境丹助缘，巅峰方可飞升（永不致死）；难度整体上调。
- **比武可选手**：自选对手（境界 / 职业 / 强度具现）。
- **及冠机制**：16 岁前为「幼年」，行动受限；及冠后开启全部玩法。
- **回忆录与继承**：一世终结后载入回忆录，按类别详记<b>一生机缘</b>（小机缘 / 大机缘 / 大气运仙缘洞天灵脉）、<b>所习功法</b>、<b>尊号称号</b>（依一生成就评定）、<b>立派宗门</b>与<b>子嗣</b>（注明与第几任道侣所出）、<b>光辉时刻</b>（上限放宽至 30 条）；飞升有尊号与成就结算；可择后裔继承遗泽再启新世。

## 操作

点击按钮行动，或在输入框输入自由指令：

```
修炼 / 前往昆仑墟 / 探索 / 采药 / 出手 / 运物 / 蓄力 / 使用疗伤丹 / 休息 / 商店 / 存档
```

## 存档说明

- 存档保存在浏览器本地（`localStorage`），按设备 / 浏览器隔离，**不会上传，也不会与他人共享**。
- **换设备续玩**：在「选档」中「导出」存档码（base64），在另一台设备「导入」即可，实现随身客制化存档。
- 共三个档位，支持读取 / 导出 / 删除 / 覆盖重开。
